Игроку нужно рассортировать цветные шарики по колбам так, чтобы в каждой колбе оказались шарики только одного цвета. Головоломка тренирует логическое мышление и внимание. На игровом поле расположены прозрачные колбы, из которых каждая имеет фиксированную вместительность. В начале игры во всех емкостях находятся шарики разных цветов, они лежат на дне и занимают не всю пробирку. В процессе несколько колб могут оказаться пустыми. Перемещать можно только верхний (последний) шарик, его можно положить только в пустую пробирку или в пробирку, где есть свободное место. Игра считается пройденной, когда все шарики в каждой колбе будут рассортированы по цвету, в любой момент можно сбросить и начать играть заново. Для работы игры будут задействованы 2 экрана. В первом будет заголовок игры и кнопка "Начать" , а на втором игровой экран.
